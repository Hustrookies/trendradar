任务：生成 TrendRadar 热点精选 H5（每期精选 15-20 条、中英双语标题，含 RSS 源，宁缺毋滥），push 到 GitHub Pages，并把链接发到微信。

【第一步：确定窗口】
1) 读标记文件 /opt/TrendRadar/output/.oc_last_push（格式 YYYY-MM-DD HH:MM，时区 Asia/Shanghai）。若文件不存在、或其中日期不是今天，则把"上次时间"视为今天 00:00。把上次时间的 HH-MM（连字符）形式记为 TH。

【第二步：取候选并做精确去重（必须用脚本，不要自己逐条比对）】
2) 把下面脚本中的 <今天YYYY-MM-DD> 和 <TH> 替换为实际值后执行。脚本会自动完成：抓取当天热榜与 RSS 候选、用已推送台账按 URL 和标题精确去重、输出近 48 小时已推送标题清单。
python3 - <<'PY'
import sqlite3, json, re, datetime
TODAY='<今天YYYY-MM-DD>'; TH='<TH>'
try:
    led=json.load(open('/opt/TrendRadar/output/.oc_pushed_items.json'))
except Exception:
    led=[]
urls={e['url'] for e in led}
norm=lambda s: re.sub(r'\W+','',s).lower()
tset={norm(e['title']) for e in led}
cutoff=(datetime.date.fromisoformat(TODAY)-datetime.timedelta(days=2)).isoformat()
def keep(t,u): return u not in urls and norm(t) not in tset
print('===HOT===')
n=0
try:
    con=sqlite3.connect(f'file:/opt/TrendRadar/output/news/{TODAY}.db?mode=ro',uri=True)
    for r in con.execute("SELECT n.title,p.name,p.id,n.rank,n.url,n.first_crawl_time FROM news_items n JOIN platforms p ON n.platform_id=p.id WHERE n.first_crawl_time>=? AND (n.rank<=20 OR p.id IN ('thepaper','cls-hot','wallstreetcn-hot','ifeng')) ORDER BY n.rank,n.first_crawl_time DESC",(TH,)):
        if keep(r[0],r[4]):
            print('|'.join(map(str,r))); n+=1
            if n>=150: break
except Exception as ex:
    print('HOT-ERROR:',ex)
print('===RSS===')
n=0
try:
    con=sqlite3.connect(f'file:/opt/TrendRadar/output/rss/{TODAY}.db?mode=ro',uri=True)
    for r in con.execute("SELECT i.title,f.name,i.url,i.first_crawl_time FROM rss_items i JOIN rss_feeds f ON i.feed_id=f.id ORDER BY i.first_crawl_time DESC"):
        if keep(r[0],r[2]):
            print('|'.join(map(str,r))); n+=1
            if n>=120: break
except Exception as ex:
    print('RSS-ERROR:',ex)
print('===RECENT-TITLES===')
for e in led:
    if e.get('date','')>=cutoff: print(e['title'])
PY
注意：热榜库 first_crawl_time 是 HH-MM（连字符），RSS 库是 HH:MM（冒号）。当前可用的 RSS 源共 4 个：Hacker News、CNBC 国际(财经)、France 24、NPR News；其他源（BBC/纽约时报/德国之声/NHK/雅虎财经/Korea Herald）网络受限，忽略。

【第三步：语义去重】
3) 把脚本输出的候选与 ===RECENT-TITLES===（近 48 小时已推送标题）对照：与其中某条属于同一新闻事件且没有新信息、新角度的，剔除；同一事件的新进展（当事人/机构新表态、数据更新、局势推进、新的回应或后续）算新新闻，可以入选。财联社电报等一条标题含多个独立事件时按单个事件判断，只要含有清单中没有的新事件即可保留。

【第四步：选题（严格执行以下标准）】
4) 每个可用 RSS 源每期至少入选 1 条：优先选该源窗口内（first_crawl_time 的 HH:MM >= 上次推送时间）的新条目；窗口内没有则取该源当天最新的一条；若该源当天条目已全部被去重剔除，则本期跳过该源，不得用已推送过的旧闻凑数。
5) 语义分类：把候选逐条归入且仅归入一类——科技 / 财经 / 国际局势 / 国内要点 / 体育 / 其他。
   - 体育以球类运动（足球、篮球、乒乓球、羽毛球、排球、网球等）为主；无球类候选时才考虑其他体育项目。
   - 一条标题涉及多类时按主体归属；娱乐八卦、社会琐事、地方小事、营销话题归入"其他"并丢弃。
6) 配额：每期总数 15-20 条（目标 18-20 条），其中科技约 40%、财经约 20%、国际局势约 20%、国内要点约 10%、体育约 10%。RSS 条目计入相应类别配额。某类别候选不足配额时，把名额让给其余类别中质量最高的候选，但总数不超过 20；合格候选总数不足 15 时按实际数量全部入选。
7) 同类别内的入选优先级：
   a. 权威媒体来源优先：澎湃新闻、财联社、华尔街见闻、凤凰网，以及各 RSS 源；百度热搜/今日头条/知乎/bilibili 榜单中来自官方媒体或权威机构账号的条目视同权威媒体；
   b. 热榜按排名更高（rank 数字更小）者优先，RSS 按时间新者优先；
   c. 同一话题跨来源重复出现时只保留一条（按 a 的优先级选来源）。

【第五步：生成内容】
8) 标题语言规则：
   - 中文来源（热榜各平台）：标题保持中文原样，不翻译。卡片格式：
     <div class="card"><span class="badge">来源 · 第N名</span><a href="URL" target="_blank" rel="noopener">标题原文</a></div>
   - 非中文来源（RSS）：生成中英对照，中文翻译为主标题、英文原标题为副标题。卡片格式：
     <div class="card"><span class="badge">来源名 · RSS</span><a href="URL" target="_blank" rel="noopener"><span class="t-main">中文翻译标题</span><span class="t-sub">英文原标题</span></a></div>
   中文翻译要准确简洁、符合新闻标题习惯，不得编造原文没有的内容。
9) 生成 {{CONTENT}}：按 科技→财经→国际局势→国内要点→体育 的顺序，每个类别一个 <div class="group">类别名 · N条</div>，其下依次放置卡片。{{TITLE}} 形如"热点精选 08-10 晚间档"；{{DESC}} 为一句话本期概述（点出本期最重要的 1-2 条）。
10) 读取 /opt/trend-digest/repo/template.html，替换 {{TITLE}}、{{DESC}}、{{CONTENT}} 三个占位符，写入 /opt/trend-digest/repo/<YYYY-MM-DD-HHMM>.html，并把同样内容复制为 /opt/trend-digest/repo/index.html。
11) 删除 /opt/trend-digest/repo 目录下修改时间超过 7 天的 <YYYY-MM-DD-HHMM>.html 旧期刊（保留 index.html、cover.png、template.html）。
12) 提交推送：cd /opt/trend-digest/repo && git add -A && git commit -m "digest <YYYY-MM-DD-HHMM>" && GIT_ASKPASS=/root/.gh-askpass.sh git push origin main。若 push 被拒（远端有新提交），先 git pull --rebase origin main 再重新 push。
13) 轮询发布：对 https://hustrookies.github.io/trendradar/<YYYY-MM-DD-HHMM>.html 每 15 秒 curl -sI 一次，最多等 3 分钟，直到返回 200。
14) 返回 200 后，把链接 https://hustrookies.github.io/trendradar/<YYYY-MM-DD-HHMM>.html 连同 {{DESC}} 发送给我；若 3 分钟仍非 200，改发 https://hustrookies.github.io/trendradar/index.html 并注明发布可能延迟。
15) 推送成功后更新两个状态文件：
   a. 把当前时间（Asia/Shanghai，格式 YYYY-MM-DD HH:MM）写回 /opt/TrendRadar/output/.oc_last_push；
   b. 把本期入选的每条条目追加进台账 /opt/TrendRadar/output/.oc_pushed_items.json（字段：title=卡片上的中文标题原文、url=卡片链接、date=今天YYYY-MM-DD、issue=<YYYY-MM-DD-HHMM>），并删除台账中 date 距今超过 7 天的条目。
   台账只在页面成功 push 之后更新；本次若 NO_REPLY，则两个文件都不要写。
16) 若候选经去重后为空，回复 NO_REPLY，不生成文件、不提交、不推送。
